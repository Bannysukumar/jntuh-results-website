# AdSense review checklist (Mana JNTUH Results)

Use this **after** each rejection to improve odds on the next request. Google does not publish exact thresholds; “low value content” usually means **not enough original, user-first editorial content** vs. **ads + thin tool pages**.

## Before you click “Request review”

1. **Deploy latest changes** and open the site in an **incognito** window (mobile + desktop).
2. **Homepage** must show visible headings and paragraphs (not only links/forms). Open `/student-resources` and confirm long-form text loads.
3. **Policy pages** must be reachable in 1–2 clicks: About, Privacy, Disclaimer, Contact, FAQ.
4. **`ads.txt`** stays valid and **authorized** in AdSense for this exact hostname.
5. **No accidental `noindex`** on important pages (check `robots` metadata on main routes).

## Things that often cause repeat rejections

- **Tool-only site**: mostly hall-ticket forms + ads, little reading material. Mitigation: keep expanding **Student Resources**, Guide, FAQ, About with **unique** helpful text.
- **Free subdomain** (`*.vercel.app`): some publishers move to a **custom domain** after consistent content; not required by policy, but can help trust and branding.
- **Traffic / age**: new sites may need time; keep publishing **real** updates (notifications commentary is not required—avoid fake news).
- **Ad balance**: ensure **content is clearly above the fold** and not dominated by ads on first screen (adjust ad components if needed).

## Manual steps outside the codebase

- **Google Search Console**: verify property, submit `sitemap.xml`, inspect a few URLs.
- **Search Quality**: read Google’s “Creating helpful, reliable, people-first content” and thin-content guidance; align pages with that intent.

## If rejected again

- In AdSense, note the **exact** policy name (low value vs scrapped content vs navigation, etc.)—each needs different fixes.
- Consider **Mediavine / Ezoic / affiliate** only after you have policy clarity; always follow their rules too.
