# Contributing to JNTUH Results Website

Thanks for your interest in contributing to this open-source project.

## How to contribute

1. Fork [Bannysukumar/jntuh-results-website](https://github.com/Bannysukumar/jntuh-results-website).
2. Create a branch for your change.
3. Make a focused change and describe it clearly.
4. Open a pull request against the default branch.

## Good first contributions

- Fix a bug and explain how to reproduce it
- Improve setup notes in the README
- Add tests or sample data where the project already has them

## Reporting issues

Open a GitHub issue with what you expected, what happened, and the steps to reproduce it.
